# AsetKPM

Sistem web yang di-deploy di [asetkpm.akmalmarvis.com](https://asetkpm.akmalmarvis.com)

## Tentang Sistem

Repositori ini mengandungi kod sumber dan eksport pangkalan data untuk sistem **AsetKPM**.

## Struktur Projek

```
/db          - Eksport pangkalan data (.sql)
/public      - Fail awam (public access)
.gitignore   - Senarai fail yang dikecualikan
README.md    - Dokumentasi ini
```

## Deployment

- **Hosting:** JimatHosting (nova.ix-dns.com)
- **URL:** https://asetkpm.akmalmarvis.com
- **Stack:** PHP / Laravel
